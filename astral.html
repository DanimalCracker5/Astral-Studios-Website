About the game

About Astral

Astral is an open-world sandbox developed by Daniel Gentry. Drive vehicles, build with placeable objects, fight enemies, earn in-game currency, and explore using astral projection.

The game is actively being developed in early access. Bugs and unfinished features should be expected while new content and improvements are added.
